Build publication-quality figures locally.

Oscilla uses Python for scientific computation and Matplotlib for the final figure. The browser is a control surface for the backend, not a screenshot renderer.

Run it

  1. Create a virtual environment.
  2. Install dependencies with pip install -r requirements.txt.
  3. Start with python app.py.
  4. Open http://127.0.0.1:8765.

Architecture

app.py owns HTTP routes and session state. backend/audio.py loads WAV files. backend/analysis.py wraps NumPy and SciPy analysis. backend/plotting.py converts analysis results into Matplotlib figures. backend/export.py writes publication files. Templates and static assets contain the UI.

Analysis modes

Waveform uses the selected channel and time region. FFT uses NumPy with the selected window and zero padding. PSD and Welch use scipy.signal.welch. Spectrogram uses scipy.signal.spectrogram with nperseg, noverlap, window, detrending, and scaling. Histogram and scatter operate on the selected signal region.

Projects

Save project downloads JSON containing analysis, styling, axes, annotations, and export settings. WAV data is never embedded. Load the JSON later and load the referenced audio file again.

Extend it

To add an analysis, add a branch in backend/analysis.py, a button in the analysis list, and any mode-specific controls in the template. Rendering stays centralized in backend/plotting.py.
